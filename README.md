## 👥 User Stories

### 🃏 Customer (ลูกค้า)
* **Authentication:**
  * As a new user, I want to register an account using only a username , email and password so that I can quickly start my card collection.
  * As a returning user, I want to log in to my account so that I can access my profile.
* **Browsing & Searching:**
  * As a customer, I want to browse products by categories (Single, Booster Pack, Booster Box, Accessories) so that I can find exactly what I am looking for.
  * As a customer, I want to search for products by card name so that I can easily find a specific card.
  * As a customer, I want to see the product image, price, and current stock levels so that I can make an informed purchasing decision.
  * As a customer, I want to filter cards by Card Game so that I can find specific cards for my deck.
  * As a customer, I want to sort products by Price and Newest Arrivals so that I can manage my budget and see the latest items.
* **Purchasing:**
  * As a customer, I want to add items to my cart and update their quantities so that I can purchase my desired products.
  * As a customer, I want to place an order and proceed to checkout (without requiring online payment) so that I can secure my items easily.

---

### 🛡️ Admin (ผู้ดูแลระบบ)
* **Inventory Management:**
  * As an admin, I want to add, edit, and manage product details (Single, Packs, Boxes, Accessories) so that the storefront is always up to date.
  * As an admin, I want to input the cost and the selling price of each product so that the system can calculate and track profit.
* **Order Management:**
  * As an admin, I want to view all customer orders so that I can process them for shipping.
  * As an admin, I want to update order statuses to 'pending' or 'fulfilled' so that customers are informed about their deliveries.
